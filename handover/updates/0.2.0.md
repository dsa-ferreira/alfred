# alfred 0.2.0 update

alfred now speaks as a formal butler and addresses the owner as "sir" (or a
configured form of address). For the infra side this is a new image tag and
one renamed, one added key in `alfred.toml`. No new secrets, dependencies,
ports, volumes or migrations.

```yaml
handover_update: 1
service: alfred
from: 0.1.0
to: 0.2.0

before: []

changes:
  - change: changed
    path: components.alfred.image
    value: album.lan/alfred:0.2.0
  - change: renamed
    path: components.alfred.files[/etc/alfred/alfred.toml].ai.system_prompt
    to: components.alfred.files[/etc/alfred/alfred.toml].ai.persona
    keep_value: true
    why: >
      Breaking. The old key is now rejected at startup ("ai.system_prompt:
      unknown key"). Only matters if the template sets it; the 0.1.0
      handover left it commented out. Meaning narrowed: it now replaces only
      alfred's voice, not the operating rules.
  - change: added
    path: components.alfred.files[/etc/alfred/alfred.toml].ai.owner_address
    value: {value: "sir"}
    why: Optional; "sir" is the default, so the line can be left out.

after: []

verify:
  - "docker logs alfred  ->  'alfred started: ...' and no 'invalid configuration' error"
  - "Owner sends the bot 'what's downloading?'  ->  a short, formal reply that addresses them as 'sir' at most once"
  - "Owner sends the bot a photo  ->  \"I'm afraid I can only read text messages, sir.\""

clients: none
rollback: >
  Pin album.lan/alfred:0.1.0 again. If ai.persona was set, rename it back to
  ai.system_prompt and remove ai.owner_address (0.1.0 rejects both as unknown
  keys). No database changes, so no restore is needed.
```

## Details

The `[ai]` section of the rendered `alfred.toml` now looks like this (only
the last two keys are new or renamed; both optional):

```toml
[ai]
base_url = "http://<ollama-gpu>:11434"
model = "gemma4:12b-it-qat"
request_timeout_s = 300
max_requests_per_turn = 8
tool_result_max_chars = 4000
owner_address = "sir"          # how alfred addresses the owner; used as written, e.g. "Mr. Smith"
# persona = """..."""          # optional; replaces only the built-in butler voice
```

`owner_address` also ends the fixed messages alfred sends without the AI
(failures, "text only"), so it should be something that reads well after a
comma, such as `sir` or `Mr. Smith`. It must not be empty.
