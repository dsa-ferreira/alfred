# alfred 0.3.0 update

alfred now passes the instructions each MCP server sends when connecting
(cookbook and mcparr already send some) to the model. For the infra side this
is a new image tag and two new optional keys in `alfred.toml`. No action is
required beyond the tag. There are no new secrets, dependencies, ports,
volumes or migrations.

```yaml
handover_update: 1
service: alfred
from: 0.2.0
to: 0.3.0

before: []

changes:
  - change: changed
    path: components.alfred.image
    value: album.lan/alfred:0.3.0  # linux/amd64; see Open questions
  - change: added
    path: components.alfred.files[/etc/alfred/alfred.toml].mcp.instructions_max_chars
    value: {value: 2000}
    why: Optional; 2000 is the default, so the line can be left out.
  - change: added
    path: components.alfred.files[/etc/alfred/alfred.toml].mcp_servers[*].use_server_instructions
    value: {value: true}
    why: Optional, per server; true is the default, so the line can be left out.

after: []

verify:
  - "docker logs alfred  ->  'alfred started: ...' and no 'invalid configuration' error"
  - "Owner asks the bot to add a short recipe with US units  ->  the log shows a cookbook_list_units tool call before cookbook_create_recipe"
  - "docker logs alfred  ->  no 'characters of instructions; cut to' warning for cookbook or mcparr"

clients: none
rollback: >
  Pin album.lan/alfred:0.2.0 again. If the template sets
  mcp.instructions_max_chars or any use_server_instructions, remove them:
  0.2.0 rejects both as unknown keys. No database changes, so no restore is
  needed.
```

## Details

Every turn, alfred adds the instructions of each reachable MCP server to the
model's system prompt. It reads them on the connection it already opens to
list tools, so there are no extra requests. The new keys only bound or mute
that text:

```toml
[mcp]
list_timeout_s = 10
call_timeout_s = 60
instructions_max_chars = 2000      # each server's instructions are cut to this; a warning is logged

[[mcp_servers]]
name = "mcparr"
# ...
use_server_instructions = true     # false keeps the server's tools but drops its instructions
```

`instructions_max_chars` must be a positive integer. Today cookbook sends
about 700 characters, well under the default.
